# Python From Zero

**A beginner-friendly Python learning program by Nuel Logics**

Welcome to **Python From Zero** — a learning program designed to help absolute beginners understand programming, learn Python, and build a strong foundation for their programming journey.

You don't need prior programming experience to get started. Follow the lessons, study the handouts, practice what you learn, and ask questions whenever you get stuck.

## About the Program

Python From Zero takes you from the fundamentals of programming to writing your first Python programs. Our goal is to make programming easier to understand, practical, and accessible to beginners.

## How to Use This Repository

1. **Watch:** Open the session documentation and watch the linked video lesson.
2. **Read:** Study the corresponding PDF handout.
3. **Practice:** Follow the examples and attempt the exercises provided.
4. **Ask questions:** Bring your questions and coding challenges to the learning community.
5. **Review:** Revisit the lessons and materials whenever you need to reinforce your understanding.

## What You Need

* A smartphone or computer.
* An internet connection to access the online lessons and materials.
* A Python coding environment. We recommend Visual Studio Code for laptop users.
* Curiosity, consistency, and a willingness to practice.
